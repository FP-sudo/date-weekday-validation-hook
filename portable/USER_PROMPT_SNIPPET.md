# 日付-曜日チェック（ユーザープロンプト貼り付け版）

> システムプロンプトを編集できない通常チャット向け。
> 日本語コンテンツ生成を依頼するときに、プロンプト冒頭にコピペして使う。

---

## 短縮版（1行）

```
【重要】出力前に本文中の「日付+曜日」表記(例: 4月29日(水))をツェラーの公式で全件検算し、不一致があれば自動修正してから出力すること。
```

## 標準版（3行）

```
【出力前セルフチェック・必須】
本文中の「YYYY年M月D日(曜)」「M月D日(曜)」「YYYY/M/D(曜)」等の日付+曜日表記をすべて抽出し、ツェラーの公式で実際の曜日を計算して照合せよ。年省略時は現在年(3ヶ月以上過去なら翌年)を仮定。不一致があれば草稿を自力で修正し、修正後にもう一度全件チェック。確認完了後にのみ出力せよ。「おそらく」「確認してください」での丸投げ禁止。
```

## 詳細版（フルスペック）

```
【MANDATORY】日本語コンテンツ生成時の日付-曜日整合性チェック

以下を出力の直前に必ず実行:

1. 本文・件名・CTA・PS・画像キャプションから、下記パターンを全件抽出:
   - `YYYY年M月D日(曜)` / `YYYY年M月D日（曜曜日）`
   - `M月D日(曜)` （年省略可）
   - `YYYY/M/D(曜)` / `YYYY-M-D(曜)`
   - `M/D(曜)`
   - カッコは半角()・全角（）両対応、曜日は月火水木金土日の単体/「○曜」/「○曜日」すべて対象

2. 年省略時: 現在年を仮定、現在から3ヶ月以上過去なら翌年を仮定

3. 各日付をツェラーの公式で実際の曜日に変換し、本文の曜日と照合

4. 不一致があれば草稿を自力で修正 → もう一度1〜3を実行 → 不一致ゼロを確認

5. 確認後のみ出力。自己修正した場合は末尾に「[日付修正] X月Y日(誤)→(正)」と1行付記

【禁止】「確認してください」とユーザーへ丸投げ / 推測で曜日を書く / 存在しない日付(2月30日等) / チェックスキップ

上記を完了した後、以下の依頼に応答せよ:
---
[ここに通常の依頼を書く]
```

---

## 使用例

### Claude Desktop での使い方
1. 新規チャットを開く
2. 上記「標準版」をコピー
3. 下に「2026年4月のメルマガを作って」など通常依頼を続ける
4. Claudeが出力前にセルフチェックを実行

### ChatGPT での使い方
1. 新規チャットを開く（または既存チャット）
2. 同様に貼り付けて依頼
3. GPT-4o/o1 以上推奨（計算精度のため）

### 運用のコツ
- 長いやり取りだとチェックが薄れるので、**10ターンごとに再注入**推奨
- カスタムGPT / Claude Projects に入れられるなら `SYSTEM_PROMPT.md` の方を使う
- 重要配信は最終チェックに人間の目も通すこと（プロンプトは保険）
